# Final Project - Machine Learning for Big Data

### Semantic search and recommendation system for Chanel products, leveraging text and image embeddings.

This project was developed for the Machine Learning for Big Data course. It features an interactive application to search for and recommend luxury products (Chanel) using advanced techniques in computer vision (images) and natural language processing (text).

## 🚀 Features

The Streamlit application offers three search modes:
1. **Image Search**: Upload an image to find visually similar products using the **ResNet50** feature extractor.
2. **Text Search**: Enter a description to find matching products via textual embeddings generated by **Sentence-Transformers**.
3. **Combined Search**: Merges visual and textual information for high-precision recommendations.

## 🛠️ Technologies Used

- **Python 3.x**
- **Streamlit**: Web-based user interface.
- **TensorFlow / Keras**: Utilizing the pre-trained **ResNet50** model for image processing.
- **Sentence-Transformers**: `all-MiniLM-L6-v2` model for textual descriptions.
- **Pandas & NumPy**: Data manipulation and matrix calculations.
- **Scipy**: Cosine similarity calculation.

## 📂 Project Structure

- `StreamlitApp.py`: Main web application code.
- `ProjetFinal_PF.ipynb`: Notebook for data preparation, embedding extraction, and analysis.
- `data_emb.csv`: Pre-calculated textual embeddings.
- `resnet50_image_embeddings.parquet`: Pre-calculated image embeddings.
- `requirements.txt`: List of Python dependencies.

## ⚙️ Installation and Usage

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd ProjetFinal
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   streamlit run StreamlitApp.py
   ```
